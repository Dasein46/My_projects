# Computer Vision — исследовательские проекты

**Автор: Эдуард Леонов** · [GitHub-профиль](https://github.com/Dasein46)

Серия практических проектов по **классификации медицинских изображений** и эксперименту с **генерацией спутниковых снимков**. Работы демонстрируют подготовку датасетов изображений, построение и обучение нейросетей, оценку качества и прототипирование моделей.

> **Статус:** учебные и исследовательские прототипы. Это не медицинские изделия, модели не предназначены для диагностики или принятия клинических решений. Описанные результаты получены в условиях конкретных экспериментов и не подтверждают качество на новых клинических данных.

## Примеры результатов из сохранённых экспериментов

- **Рентген, пять классов:** 5 709 изображений, из них 4 568 для обучения и 1 141 для валидации. В сохранённом выводе ноутбука зафиксирована **validation accuracy 98,94%** после трёх эпох.
- **МРТ, четыре класса:** 3 329 изображений для обучения и 830 для валидации. В сохранённом выводе ноутбука зафиксирована **validation accuracy 98,12%** после трёх эпох.
- **Мультиразметочный рентген:** в README эксперимента указаны **F1-macro ≈ 0,797** и **F1-micro ≈ 0,899** при пороге 0,5.

**Как интерпретировать:** это результаты отдельных экспериментов, а не независимая оценка на внешнем тестовом наборе. Разбиение по пациентам, переносимость на данные других учреждений и клиническая валидность требуют отдельной проверки. Для проектов по УЗИ метрики и методику проверки стоит уточнить по сохранённым ноутбукам перед вынесением результатов на главную страницу.

## Инструменты и навыки

**Python**, pandas, NumPy, **TensorFlow / Keras**, **PyTorch / fastai**, свёрточные нейросети, **transfer learning**, обработка изображений, аугментация, обучение и оценка моделей; эксперименты выполнялись в **Google Colab**.

В репозитории сохранены исследовательские `Jupyter Notebook`-файлы. Работы выполнены с использованием открытых датасетов и внешних ресурсов, ссылки на которые приведены в README отдельных проектов.

## Навигация и воспроизводимость

1. Перейдите в каталог интересующего проекта и откройте его `README.md` и `.ipynb`.
2. Изучите источник датасета, подготовку данных, архитектуру модели, этапы обучения и сохранённые результаты.
3. Для повторного запуска потребуется отдельно скачать данные и заменить абсолютные пути Google Colab / Google Drive на собственные. **Полная воспроизводимость одним запуском сейчас не заявляется**; совместимость зависимостей и внешние ссылки необходимо проверить.
4. Обученные веса не входят в Git-репозиторий. В отдельных README имеются внешние ссылки на модели, их доступность не гарантируется.

### Ограничения

- Для медицинских изображений особенно важно исключать попадание изображений одного пациента одновременно в обучение и валидацию. Существующие ноутбуки не следует трактовать как подтверждение независимой пациент-ориентированной оценки.
- Высокая accuracy может скрывать проблемы отдельных классов и дисбаланс данных; для содержательной оценки нужны матрицы ошибок, precision/recall/F1 и результаты на независимом тесте.
- Старые эксперименты полезны как демонстрация практики Computer Vision, но не являются production-сервисами и не сопровождаются CI/CD или развёрнутым API.
