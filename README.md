# Computer Vision — 6 исследовательских проектов

**Python · TensorFlow/Keras · PyTorch/fastai · CNN · Transfer Learning · Image-to-Image Regression**

Коллекция из шести экспериментов: классификация медицинских изображений (в том числе мультиразметочная) и преобразование спутниковых снимков между сезонами. Основной акцент при технической ревизии сделан на корректном разделении данных, контроле утечек, оценке моделей и воспроизводимости.

> **Статус:** техническая работоспособность проверена на синтетических данных; полного повторного обучения и независимой оценки на оригинальных датасетах после исправлений **не было**. Медицинские модели не предназначены для клинического применения.

## Что улучшено при ревизии

- **Контроль утечек:** разбиение медицинских данных по пациентам, спутниковых — по городам до нарезки тайлов; проверка пересечений и точных дубликатов.
- **Корректность оценки:** разделение train/validation/test, отсутствие случайной аугментации на validation/test, контроль последнего батча, метрики под тип задачи.
- **Воспроизводимость:** общий модуль `cv_common`, манифесты и проверки хешей, отдельные директории результатов, checkpoint/reload, инструкции запуска.
- **Автотесты:** синтетические проверки обучения, инференса, метрик и CLI. Тяжёлые тесты TensorFlow и PyTorch выполняются в отдельных процессах.

**Последний зафиксированный прогон: 51 passed, 14 warnings, 179.85s на CPU (12.11.2026).** Это проверка программной логики, а не подтверждение качества моделей на реальных данных. Подробности — [VALIDATION.md](VALIDATION.md).

## Как запустить

Нужен **Python 3.12** и локальные данные соответствующего проекта. Клонируйте весь репозиторий: ноутбуки импортируют `cv_common`.

```bash
python -m venv .venv
# Linux/macOS:
source .venv/bin/activate
# Windows PowerShell:
# .venv\Scripts\Activate.ps1
python -m pip install -r requirements-keras.txt
# Для проектов PyTorch/fastai используйте отдельное окружение:
# python -m pip install -r requirements-torch.txt
python -m pip install jupyterlab
jupyter lab
```

Для медицинских проектов нужен CSV-манифест `filename,label,patient_id[,split]` с проверенными обезличенными идентификаторами пациентов. `split` необязателен; при его отсутствии выполняется групповое разбиение с seed=12345. Пути задаются через `DATA_ROOT`, `MANIFEST_PATH`, `OUTPUT_DIR`. Не подменяйте `patient_id` идентификатором отдельного снимка.

Для спутникового эксперимента смотрите CLI в README соответствующей папки.

### Тестирование

В подготовленном окружении с нужными зависимостями:

```bash
python -m pytest tests/test_data.py tests/test_notebooks.py
# В окружении PyTorch:
python -m pytest tests/test_satellite.py
```

Полный набор интеграционных проверок требует обоих стеков зависимостей; точная команда и версии — в [VALIDATION.md](VALIDATION.md).
