Дата завершённого прогона: 2026-11-12. Python 3.12, CPU.
TensorFlow 2.18.0 / Keras 3.15.1, PyTorch 2.5.1+cpu / torchvision 0.20.1+cpu,
fastai 2.7.18, segmentation-models-pytorch 0.3.4, NumPy 1.26.4.

## Результат

Команда из корня репозитория:

```bash
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 python -m pytest -q
```

**51 passed, 14 warnings in 179.85s (0:02:59).**

Тяжёлые проверки запускаются tests/conftest.py в отдельных процессах. Дочерний
процесс выполняет выбранный тест; его ненулевой код завершения вызывает ошибку
родительского теста. Память моделей освобождается после завершения процесса.

## Покрытие

- Разделение по пациентам и seed, запрет пересечений и отсутствующих идентификаторов,
  официальный split, отсутствие класса в train, точные пиксельные дубли.
- Отказ от неявной конвертации 16-bit и многокадровых изображений, включая инференс;
  защита путей и результатов от перезаписи; перенос манифеста и проверка хешей.
- Схема и синтаксис всех шести ноутбуков; отсутствие устаревших outputs.
- VGG16 preprocess_input, отсутствие случайной аугментации validation и полный
  последний батч; тренировочный батч каждой из четырёх Keras-архитектур.
- Все кодовые ячейки четырёх Keras-ноутбуков на искусственных манифестах: одна эпоха,
  checkpoint/reload, тестовая матрица ошибок и инференс.
- fastai ResNet50 forward/backward, test predictions, fine_tune, export/reload,
  инференс и полные train-батчи при 2, 3, 5, 7, 13 и 33 изображениях.
- Исходная схема train_df.csv и patient manifest мультиразметочного проекта,
  ошибочные метки, отсутствие patient_id и изменённые пиксели.
- Полнота спутниковых тайлов, парность, разделение городов и точные дубли;
  известные MAE/MSE с неполным батчем; forward/backward U-Net.
- Искусственный запуск CLI: одна эпоха, checkpoint/reload, test, identity baseline,
  визуализация; отдельная оценка сохранённого checkpoint без повторного обучения.
- Неизменность сохранённых весов, обнаружение заменённых снимков, ошибочной формы
  предсказаний и NaN/Inf; проверка некорректной test-пары до создания модели.

Предобученные веса в тестах не скачивались; модели использовали случайную
инициализацию. Эпохи в полном проходе Keras-ноутбуков сокращены до одной.

Дополнительно: pip check — No broken requirements found; git diff --check — без ошибок.
Импорт спутникового ноутбука выполнен из корня репозитория и папки проекта.
Поиск типовых шаблонов GitHub/AWS-токенов, приватных ключей и старых путей Colab
в проверяемом коде не дал совпадений; это не полный аудит секретов истории Git.

## Ограничения

Предупреждения библиотек об устаревающих API и загрузке доверенных pickle-файлов
не означают подтверждение совместимости с будущими версиями зависимостей.

Не проверены полное обучение на исходных наборах, фактические patient_id, близкие
дубли, географическая регистрация, лицензии, GPU, воспроизводимость на другом
оборудовании и загрузка предобученных весов. Синтетические проверки подтверждают
работоспособность кода, но не качество моделей или клиническую применимость.
Требования к оригинальным данным перечислены в REVIEW.md.
