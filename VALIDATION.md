# Проверки кода

Дата: 2026-11-11. Python 3.12, CPU. TensorFlow 2.18.0 / Keras 3.15.1,
PyTorch 2.5.1+cpu / torchvision 0.20.1+cpu, fastai 2.7.18,
segmentation-models-pytorch 0.3.4, NumPy 1.26.4.

Команда из корня репозитория: `python -m pytest -q`.

Проверки охватывают:
- сохранение групп пациентов и seed, запрет пересечений и пустых идентификаторов;
- точные пиксельные дубли, официальный split, отсутствие класса в train;
- отказ от неявной конвертации 16-битных изображений;
- схему и синтаксис всех шести ноутбуков, отсутствие устаревших outputs;
- соответствие VGG16 preprocess_input и отсутствие случайной аугментации validation;
- тренировочный батч всех четырёх исходных Keras-архитектур;
- загрузку мультиразметочных данных, forward/backward ResNet50 и test predictions;
- полноту тайлов, парность изображений, разделение городов и точные дубли;
- MAE/MSE на известном искусственном примере с неполным батчем;
- forward/backward U-Net и полный искусственный запуск CLI: одна эпоха,
  checkpoint, его загрузка, test, identity baseline, визуализация;
- fit небольшой Keras-модели, checkpoint/reload и оценку всех тестовых строк.

**Итог: 29 тестов пройдены.** Предобученные веса в тестах не скачивались:
архитектурные проверки выполнялись со случайной инициализацией. Есть предупреждения
зависимостей об устаревающем API и рекомендуемом явном Keras Input.

Не проверены: полное обучение на исходных наборах, фактические patient_id,
регистрация спутниковых пар, близкие дубли, лицензии, работа GPU, численная
воспроизводимость на другом оборудовании и качество предобученных весов после загрузки.
Синтетические примеры не являются результатами исследования.
