# Генерация спутниковых изображений

[← К списку проектов Computer Vision](../README.md)

## О проекте

Исследовательский ноутбук, посвящённый **генерации спутниковых изображений**.

**Исходный код:** [`Генерация_спутниковых_снимков.ipynb`](Генерация_спутниковых_снимков.ipynb).

Это отдельный эксперимент по генерации изображений, а не одна из задач классификации медицинских снимков в данном репозитории.

## Материалы

В каталоге хранится исходный Jupyter Notebook. **Итоговые метрики, архитектура генеративной модели, состав датасета и протокол эксперимента пока не подтверждены**: ноутбук содержит большое количество сохранённых данных и выводов, из-за чего не удалось надёжно прочитать и проверить его код через доступный интерфейс GitHub.

Поэтому здесь не указаны неподтверждённые результаты и не заявляется, что проект можно воспроизвести одной командой.

## Как просмотреть или подготовить эксперимент к повторному запуску

1. Откройте ноутбук по ссылке выше в GitHub или загрузите его в Jupyter / Google Colab.
2. Проверьте источники изображений, используемые библиотеки, архитектуру, параметры обучения и сохранённые результаты.
3. Перед повторным запуском настройте пути к данным и необходимые зависимости под своё окружение.
4. Для облегчения просмотра можно **в отдельной копии** удалить тяжёлые сохранённые outputs и повторно сохранить ноутбук, не изменяя сам код. Исходная версия остаётся в истории Git.

**Примечание:** пока код не перепроверен, результаты обучения и качество сгенерированных изображений не следует интерпретировать как независимо воспроизведённые.
