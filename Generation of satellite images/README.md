# Генерация спутниковых снимков

[← К списку проектов Computer Vision](../README.md)

Исследовательский проект по генерации спутниковых изображений.

**Ноутбук:** [`Генерация_спутниковых_снимков.ipynb`](Генерация_спутниковых_снимков.ipynb).

## Структура

В каталоге находится Jupyter Notebook с экспериментом. Для повторного запуска необходимо подготовить датасет и рабочее окружение в соответствии с используемыми в ноутбуке библиотеками и путями.

## Дальнейшее развитие

- Документировать источник изображений и их предварительную обработку.
- Зафиксировать конфигурацию модели и параметры обучения.
- Добавить воспроизводимые примеры сгенерированных изображений и критерии оценки качества.
- Уточнить зависимости и инструкцию запуска.

Результаты эксперимента требуют отдельной проверки перед публикацией количественных метрик.
